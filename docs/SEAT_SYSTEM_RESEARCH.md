- 조사일: 2026-11-09
- 조사 환경: Claude Code 클라우드 세션 (네트워크 제한 있음)

## 0. 조사 한계 (중요)

이번 조사 환경에서는 **학교 사이트에 직접 접속할 수 없었다.**

| 대상 | 결과 |
|---|---|
| `https://lib.inha.ac.kr` (curl) | 프록시 차단 (CONNECT 403) |
| `https://lib.inha.ac.kr` (웹 페이지 가져오기) | 세션 네트워크 허용 목록 밖이라 접속 불가 |
| `https://apps.apple.com/...` (앱 상세) | 세션 네트워크 허용 목록 밖이라 접속 불가 |
| 웹 검색 | 가능 (검색 결과 요약만 확인) |

따라서 아래 내용은 **웹 검색 결과 요약**에서 얻은 것이며, 학교 페이지 원문이나 실제 브라우저에서 확인한 내용이 아니다.
**확인 수준**은 다음과 같이 구분한다.

- **[검색 확인]** 검색 결과에 공식 도메인 페이지가 나왔고, 요약에 내용이 언급됨 (원문은 직접 보지 못함)
- **[2차 자료]** 블로그 등 비공식 자료, 오래되었을 수 있음
- **[미확인]** 확인하지 못함

## 2. 구현 가능성 판단

| 기능 | 판단 | 이유 |
|---|---|---|
| 모의 데이터 기반 전체 기능 | **구현함** | 학교 시스템과 무관 |
| 실제 좌석 현황 자동 조회 | **보류** | 공식 API/허용된 조회 방법 미확인. 실제 URL·HTML 구조도 확인하지 못했으므로 추측으로 만들지 않음 |
| 실제 좌석 자동 배정 | **구현하지 않음** | 허용 여부 미확인 + NFC 현장 확정 절차가 있을 수 있음 (현장 확인 우회 위험) |
| 공식 페이지 열기 (사용자 직접 배정) | **구현함** | 링크만 제공, 학교 시스템에 요청을 보내지 않음 |

`OfficialSeatProvider` 는 틀만 있고, 호출하면 "비활성" 오류를 돌려준다.

## 3. 사용자가 직접 확인할 일

학교 사이트는 사용자 PC 브라우저로 직접 열어볼 수 있다. 아래를 확인해 주면 다음 단계(P3)를 진행할 수 있다.

1. https://lib.inha.ac.kr 에 접속해 "좌석", "열람실", "시설 예약" 메뉴 위치와 화면 모습
2. 로그인 없이 열람실 좌석 현황(빈자리 수)을 볼 수 있는지
3. 이용 규정 페이지에 자동화 프로그램·매크로 관련 조항이 있는지

## 4. 학교 담당 부서에 보낼 질문 (초안)

> 안녕하세요. 인하대학교 재학생 OOO입니다. 개인적으로 일반열람실 빈자리를 확인하는 프로그램을 만들려고 합니다.
>
> 1. 열람실 좌석 현황을 조회할 수 있는 공식 API나 공개 데이터가 있나요?
> 2. 좌석 현황 페이지를 개인 프로그램으로 주기적으로(예: 1분에 1번) 조회해도 되나요? 허용되는 조회 간격이 있나요?
> 3. 자동으로 좌석을 배정받는 프로그램(매크로) 사용이 규정상 허용되나요? 금지라면 근거 규정은 무엇인가요?
> 4. 좌석 배정 확정에 NFC 현장 인증이 필수인가요? 일반열람실에도 적용되나요?
> 5. 열람실별 좌석 수와 배치도를 공개하고 있나요?
